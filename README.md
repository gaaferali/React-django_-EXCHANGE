Trading and Exchanging Used Furniture - Frontend
Project Overview
A modern React TypeScript web application for trading, selling, and exchanging used furniture. Built with responsive design using Bootstrap and styled components.

Technology Stack django + react +sqlLit
Frontend Framework: React 18.x
Language: TypeScript
Routing: React Router v6
HTTP Client: Axios
State Management: React Context (Auth Context)
Styling: Bootstrap 5
Package Manager: NPM
backend framework: django
## Features
- chat real time using channel and socket
- User authentication (JWT)
- CRUD operations
- Responsive UI
- REST API

## Tech Stack
**Frontend**
- React
- Vite
- typescript
- bootstrab CSS

**Backend**
- chat real time using channel and socket
- Django
- Django REST Framework
- sqlLite
- JWT Authentication


## Installation

```

### Frontend

cd frontend
npm install
npm run dev

### Backend

cd backend
python -m venv venv
venv\Scripts\activate  
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Frontend
